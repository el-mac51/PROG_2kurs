# Лабораторная работа 2. Паттерн «Декоратор». Получение и форматирование курсов валют
### Елькин М.О. ИВТ-1.2 2 курс

## Цель работы
Изучение и реализация паттерна проектирования «Декоратор» в Python. В ходе работы создан модуль для получения актуальных курсов валют с API Центробанка РФ и реализованы декораторы для преобразования данных в форматы YAML и CSV с возможностью сохранения в файлы.

## Выполнение работы

### Базовый компонент — `currency_component`

Реализован абстрактный базовый класс, определяющий интерфейс для всех компонентов системы.
Класс наследуется от `ABC` и содержит абстрактный метод `get_data() -> dict`, который обязаны реализовать все наследники. Это обеспечивает единый контракт: любой компонент, участвующий в цепочке, должен уметь возвращать данные о курсах валют в виде словаря.

### Конкретный компонент — `centralbank_api`

Реализован класс, получающий данные с публичного API Центробанка РФ.
Метод `get_data()` выполняет HTTP-запрос к эндпоинту `https://www.cbr-xml-daily.ru/daily_json.js`, парсит ответ в формате JSON и возвращает словарь с полной структурой данных. Класс наследуется от `currency_component` и предоставляет «сырые» данные для дальнейшей обработки декораторами.

### Базовый декоратор — `currency_decorator`

Реализован промежуточный класс, обеспечивающий обёртку вокруг компонента.
Класс хранит ссылку на обёрнутый объект в атрибуте `_component` и делегирует вызов `get_data()` этому объекту. Это позволяет строить цепочки декораторов: каждый следующий декоратор может принимать на вход как базовый компонент, так и другой декоратор.

### Декоратор YAML — `yaml_decorator`

Реализован конкретный декоратор для преобразования данных в формат YAML.
Метод `get_data() -> str` получает словарь от обёрнутого компонента и преобразует его в строку YAML с помощью функции `yaml.dump()` с параметрами `default_flow_style=False` (блочный формат) и `allow_unicode=True` (поддержка кириллицы). Метод `save_to_file(filename: str)` записывает результат в файл с кодировкой UTF-8.

### Декоратор CSV — `csv_decorator`

Реализован конкретный декоратор для преобразования данных в формат CSV.
Метод `get_data() -> str` фильтрует полученные данные: из полной структуры API извлекаются только коды валют и их курсы (ключ `'Value'` внутри `'Valute'`). Затем с помощью `csv.DictWriter` и `io.StringIO` формируется CSV-строка с заголовками и значениями. Метод `save_to_file(filename: str)` сохраняет результат в файл.

## Тесты

Для проверки корректности реализации написаны юнит-тесты с использованием модуля `unittest`. Проверены:

1. Работа компонента `centralbank_api` — возвращает словарь, содержит ключи валют.
2. Работа декоратора `yaml_decorator` — возвращает строку, содержит признаки YAML-формата.
3. Работа декоратора `csv_decorator` — возвращает строку, содержит заголовки и значения через запятую.
4. Методы `save_to_file` — создают файлы с указанными именами.
5. Цепочка декораторов — базовый декоратор корректно делегирует вызов компоненту.

## Вывод

В ходе работы изучен и реализован паттерн «Декоратор» на примере модуля получения курсов валют.

Рассмотрены ключевые принципы паттерна:
- **Единый интерфейс** через абстрактный базовый класс `currency_component`;
- **Делегирование** вызовов через базовый декоратор `currency_decorator`;
- **Расширение поведения** без изменения исходного кода компонента — новые форматы добавляются через новые классы-декораторы.

Реализованы два конкретных декоратора:
- **`yaml_decorator`** — преобразует данные в читаемый формат YAML;
- **`csv_decorator`** — фильтрует и преобразует данные в табличный формат CSV.

Изучены практические аспекты работы с внешними API (`requests`), сериализации данных (`yaml`, `csv`).
