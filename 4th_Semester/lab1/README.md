# Лабораторная работа 1. Итераторы, генераторы, сопрограммы

## Цель работы
Изучение концепций итераторов, генераторов и сопрограмм в Python. В ходе работы реализованы два способа создания итераторов для генерации чисел Фибоначчи, а также исследованы принципы работы сопрограмм.

## Выполнение работы

### Задание 1.1 — Класс-итератор
Реализован классический итератор на основе класса с использованием протокола итерации.

Итератор определяется методами `__iter__()` и `__next__()`. Первый возвращает сам объект итератора, второй — следующий элемент, а при исчерпании последовательности выбрасывает исключение `StopIteration`.

Класс `FibonacciIterator` генерирует числа Фибоначчи до заданного количества. Состояние итератора хранится в атрибутах `a`, `b` и `current`. При каждом вызове `__next__()` возвращается очередное число и обновляется внутреннее состояние.

### Задание 1.2 — Генераторная функция
Реализован альтернативный подход с использованием генераторной функции.

Генераторная функция содержит ключевое слово `yield`, что позволяет Python автоматически создать объект-итератор. Состояние выполнения сохраняется между последовательными вызовами.

Функция `fibonacci_generator()` возвращает числа Фибоначчи через `yield`. В отличие от классового итератора, здесь не требуется явно реализовывать протокол итерации — итератор создаётся неявно при вызове функции.

### Задание 2 — Сопрограмма
Реализована сопрограмма, формирующая список чисел Фибоначчи по запросу.

Сопрограмма представляет собой генератор, который может принимать данные через метод `send()`. Это обеспечивает двустороннюю связь между вызывающим кодом и генератором.

Функция `fibonacci_coroutine()` принимает количество элементов через `send()` и возвращает соответствующий список. Бесконечный цикл `while True` позволяет обрабатывать множество последовательных запросов без повторного создания сопрограммы. Бесконечная последовательность чисел Фибоначчи генерируется вспомогательным генератором `fib_elem_gen()`, из которого с помощью `itertools.islice` извлекается необходимое количество элементов.

Декоратор `coroutine()` автоматически инициализирует сопрограмму вызовом `next()`, продвигая её до первого `yield` и подготавливая к приёму данных.

## Тесты
Для проверки корректности реализации написаны юнит-тесты с использованием модуля `unittest`. Проверены:

1. Работа итератора `FibonacciIterator` — количество элементов и их значения.
2. Работа генератора `fibonacci_generator` — количество элементов и их значения.
3. Работа сопрограммы `fibonacci_coroutine` с различными входными параметрами.
4. Граничные случаи: нулевое количество элементов, многократные запросы к одной сопрограмме.

## Вывод
В ходе работы изучены и реализованы основные механизмы работы с последовательностями в Python.

Рассмотрены два подхода к созданию итераторов:
- **Классовый итератор** — с явным управлением состоянием через методы `__iter__()` и `__next__()`;
- **Генераторная функция** — с автоматическим управлением состоянием за счёт использования `yield`.

Изучена концепция сопрограмм как расширения генераторов, позволяющего организовать двустороннее взаимодействие через метод `send()`. Реализована возможность многократных запросов к одной сопрограмме без необходимости её повторного создания.
